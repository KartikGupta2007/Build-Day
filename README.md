## Description

This is a Copy-Paste utility web application that allows users to copy text to their clipboard and paste text from their clipboard using simple buttons.

## Features

- Copy text to clipboard
- Paste text from clipboard
- Clean and modern user interface
- Responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript (Clipboard API)

## How to Use

1. Open `index.html` in your browser
2. Enter text in the first textarea and click "COPY!" to copy it to your clipboard
3. Click "PASTE!" in the second section to paste text from your clipboard
